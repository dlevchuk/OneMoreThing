# ✦ OneMoreThing — персональний вішліст

Публічний вішліст на GitHub Pages. Усі відвідувачі можуть переглядати картки, шукати й фільтрувати список. Додавання карток доступне через редактор файлу в GitHub; GitHub дозволяє запис лише користувачам із правами на репозиторій.

## Як додати бажання

Натисни **«Редагувати список»** на сайті. GitHub відкриє `data/wishes.json`. Додай новий об'єкт у масив і збережи зміни в гілку `main`. Після оновлення GitHub Pages картка з'явиться на сайті.

```json
[
  {
    "id": "steam-deck",
    "title": "Steam Deck",
    "description": "Портативна ігрова консоль",
    "image": "https://example.com/steam-deck.jpg",
    "originalUrl": "https://example.com/product",
    "localUrl": "https://local-market.example/product",
    "priority": "want"
  }
]
```

`description`, `image`, `originalUrl` і `localUrl` необов'язкові. `priority`: `want`, `nice` або `unsure`.

**Важливо:** кнопка редагування видима всім, але записати зміни безпосередньо в репозиторій можуть лише користувачі з правами write. Не додавай інших користувачів як співавторів із правом запису, якщо картки маєш додавати лише ти. На GitHub Pages без бекенда не можна зробити власну захищену веб-форму, яка пише до GitHub від імені власника.

## Публікація

GitHub Pages розгортає корінь гілки `main`: **Settings → Pages → Deploy from a branch → main / root**.

## Анімації та доступність

Картки плавно з'являються з невеликою затримкою, зображення збільшуються при наведенні, а на тлі рухається декоративний градієнт. Враховується `prefers-reduced-motion`.
